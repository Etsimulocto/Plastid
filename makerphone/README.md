**Historical folder only. Current product name: Plastid.**

This path is retained to avoid breaking early scripts, repository history and test references. Earlier app names and folder labels here are obsolete; **do not create a second product identity** from this directory.

For current system design, including **Phone + Pod + Base**, see [the Plastid root README](../README.md) and [architecture](../plastid/ARCHITECTURE.md). For current Pi app and Base/Pod simulator installation, see [Plastid Pi instructions](../plastid/README.md).

Do not overwrite the user's full Plastid UI with the minimal bench. Keep the prior source and migration paths until the full app is safely imported and the historical folder can be retired deliberately.
