# Plastid

Modular, repairable technology projects.

## MakerPhone

The first project baseline is **[MakerPhone](makerphone/README.md)**, a software-first DIY cellular flip-phone prototype. MakerPhone Lab is a host-side local simulator for PC or Raspberry Pi, not working cellular firmware.

Start with [MakerPhone Lab](makerphone/lab/README.md), the [build charter](makerphone/docs/PROJECT_CHARTER.md), and [decision log](makerphone/docs/DECISIONS.md).

Project status: simulator available; handset architecture and carrier compatibility unverified.
